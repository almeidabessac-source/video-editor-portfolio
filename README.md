# Video editor portfolio

English, responsive, dark neon portfolio. Includes three long-form embeds and three vertical embeds. All six slots are explicitly labeled as demonstrations. No clients or credentials are included.

Edit `profile.js` to replace the name, bio, photo, contacts and YouTube video IDs. Empty contact fields are hidden. Replace the demonstration notice once you add your own work.

## GitHub Pages

Create a public repository, put the contents of this folder at its root on the `main` branch, and select **Settings → Pages → Source → GitHub Actions**. The included workflow publishes the site after a push or manual run. Verify the completed Actions run and the resulting Pages URL before treating publication as successful. No paid dependencies or backend are required.

YouTube playback depends on availability, embedding permission and browser/network settings. Each embed includes an optional YouTube fallback link.
